# WPL Safety Inspection App

Monthly safety inspection checklist for Wicomico Public Library.

## Files

```
wpl-inspection/
├── index.html          ← the app
├── reference.html      ← photo numbering reference sheet
└── photos/
    ├── sarbanes/       ← 001.jpg through 073.jpg
    ├── centre/         ← 001.jpg through 010.jpg (add when available)
    └── riley/          ← 001.jpg through 007.jpg (add when available)
```

## Adding photos

Name each photo using the number from reference.html and drop it into the correct folder.
The app will display it automatically — no code changes needed.
